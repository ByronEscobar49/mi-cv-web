# Mi Portafolio Web

## Objetivo del proyecto

Este proyecto es mi página de perfil/currículum digital, desarrollada para la clase de Desarrollo Web. Mi meta fue crear un sitio responsive usando Bootstrap 5 que reflejara quién soy: mi biografía, mis habilidades, mis pasatiempos y hacia dónde quiero crecer como futuro ingeniero.

## Cómo ejecutar la página

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en VS Code.
3. Abre el archivo `index.html` directamente en el navegador, o usa la extensión **Live Server** de VS Code para verlo con recarga automática.

No requiere instalación de dependencias, ya que Bootstrap se carga por CDN.

## Componentes de Bootstrap utilizados

- **Navbar** responsive con menú colapsable en móvil.
- **Grid System** (`container`, `row`, `col`) para organizar todas las secciones.
- **List Group** para mostrar mis habilidades.
- **Badges / Rounded Pills** para categorizar cada habilidad.
- **Cards** para mostrar mis pasatiempos.
- **Bootstrap Icons** para las redes sociales en el footer.

## Qué personalicé con CSS

- Paleta de colores propia (azul oscuro + rojo como acento).
- Tipografía y espaciados ajustados en cada sección.
- Efectos hover en las cards, en los ítems de habilidades y en los íconos sociales.
- Fondo degradado en el encabezado y en la sección de visión profesional.
- Línea decorativa debajo de cada título de sección.
- Foto de perfil circular con borde y sombra.

## Decisiones de diseño

Desarrollé el sitio siguiendo el orden de las secciones pedidas, haciendo un commit por cada una para reflejar el avance real del proyecto. Elegí un diseño con tonos oscuros y un color de acento (rojo) para que las secciones más importantes, como el encabezado y mi visión profesional, resaltaran visualmente. Traté de que cada sección tuviera su propio estilo, pero manteniendo coherencia en colores, tipografía y espaciados en todo el sitio.
